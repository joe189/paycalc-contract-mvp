# Cost-Conscious Workflow

- Keep progress updates and final handoffs concise.
- Do not use subagents unless explicitly requested or clearly beneficial for independent work.
- Inspect targeted files first; expand inspection when the evidence requires it.
- Run focused tests during development, then run the complete relevant test suite before final handoff.
- Preserve all required document rendering, calculation, security, integration, and regression validation.
- Never skip validation, code review, or safety checks to save tokens or time.
- Reuse current reports, test results, fixtures, and unchanged artifacts instead of reanalyzing them.
- Avoid repeating completed investigations unless new evidence makes them relevant.
- Prefer one consolidated implementation-and-verification pass for approved, low-risk work.
- These guidelines do not override explicit user instructions or reduce the required quality bar.
